# Stayora – Online Hotel Booking and Reservation System

## 📌 Project Overview

Stayora is a modern and user-friendly hotel management and reservation system developed to simplify hotel room booking and daily hotel operations. It provides an easy-to-use interface for managing rooms, guest information, and reservations.

The project is designed using HTML, CSS, and JavaScript, with browser Local Storage for saving data.

## ✨ Features

- **Home Page:** Attractive hotel homepage with room categories and facilities.
- **Dashboard:** Displays occupancy, available rooms, maintenance status, and revenue from stays.
- **Room Management:** Add rooms, view room details, update maintenance status, and delete rooms.
- **Booking Management:** Create reservations, check booking status, and manage check-in/check-out.
- **Guest Management:** Maintain guest names, phone numbers, email addresses, and stay records.
- **Booking Filters:** Filter reservations by status.
- **Responsive Design:** Supports desktop and mobile screens.
- **Local Storage:** Saves application data in the browser.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and application logic
- Local Storage – Browser-based data storage

## 🚀 How to Run the Project

1. Download or extract the project folder.
2. Open the project in Visual Studio Code.
3. Make sure all project files are in the same folder.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code.
6. Start managing rooms, guests, and bookings.

## 🎯 Project Objective

The main objective of Stayora is to simplify hotel reservation and management activities through a digital platform. It reduces manual work, saves time, and provides an organized way to manage hotel operations.
